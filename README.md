# 🧱 Brick.ai

Brick.ai is a modern AI SaaS landing page built for a frontend hackathon. The project showcases a premium, responsive interface for an AI workflow platform where users can build intelligent workflows using modular AI "bricks".

## ✨ Features

- 🎨 Modern responsive UI built with React and Tailwind CSS
- 🧱 Modular "Brick.ai" themed hero section
- 💰 Dynamic pricing section with:
  - Currency switcher (USD, EUR, INR)
  - Monthly / Annual billing toggle
  - Dynamic pricing calculations
- 📱 Fully responsive design
- 🧩 Interactive feature cards
- ⭐ Testimonials section
- 🚀 Smooth UI animations and transitions
- 🎯 Clean component-based architecture

## 🚀 Getting Started

Clone the repository

```bash
git clone <repository-url>
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
